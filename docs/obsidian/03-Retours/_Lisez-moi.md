# 03-Retours

Un retour = une note, créée depuis le modèle **Retour-testeur**, taguée `#retour/a-trier` puis triée.
Pseudonymes T01 à T10 uniquement (voir [[Conventions]]).

`github/` contient les fiches générées des issues portant le label `retour-testeur` : titre, état et lien,
jamais le texte de l'issue.
