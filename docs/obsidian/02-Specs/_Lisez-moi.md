# 02-Specs

Une spec par fonctionnalité, créée depuis le modèle **Spec** (Ctrl+P → « Insérer un modèle »).
Méthode : spec → plan en tâches atomiques → validation écrite du porteur → code (test rouge d'abord).
Une spec reste `brouillon` ou `soumise` tant que la ligne « Validée par le porteur le » est vide.

Les specs rédigées avant le 28/11/2026 vivent dans le projet claude.ai (`claude/Repere_Spec*.md`) : on ne
les recopie pas, on les cite par leur nom quand une nouvelle spec en dépend.
